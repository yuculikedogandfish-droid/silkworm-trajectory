# 蚕轨迹描图器 · 使用介绍

> 在线地址：<https://yuculikedogandfish-droid.github.io/silkworm-trajectory/>
> 仓库：<https://github.com/yuculikedogandfish-droid/silkworm-trajectory>

本工具用于把顶视拍摄的家蚕吐丝视频，**手动描成可编辑的丝线路径**，换算成 mm 坐标与弧长参数（u∈[0,1]），再导出给 Rhino / Illustrator / Blender / TouchDesigner / p5.js 使用。视频在浏览器本地解码，**不会上传到服务器**。

页面分三层：上方是常驻并排的两块——左侧「**蚕轨迹描图器**」负责描线和导出，右侧「**吐丝运动预览**」负责回放、合成；往下滑（或点顶栏「**进入 Digital Habitat**」）是**整屏的「数字蚕室 Digital Habitat」**，它有自己的左右侧栏（左=环境，右=个体）。顶栏「**收起运动预览 / 展开运动预览**」只切换右侧预览的显隐，蚕室始终是下方的整屏区块。

---

## 一、快速上手（3 分钟）

1. **载入视频**：点顶栏「载入视频」选本地 MP4；或点「家蚕·段00」加载站内演示样片。
2. **标定**：在「标定」区点「① 设原点」，在画面上点一个格子交点；再点「② 量一格」，依次点同一格的两个对角（格边默认 10 mm，即 1 cm）。
3. **选蚕描线**：数字键 `1`–`9` 切换当前蚕，按住鼠标/数位板在画面上沿丝路拖动描线；轻点一下记一个单点。
4. **调样式**：在「曲线样式」里改颜色、头/中/尾粗细、透明度、材质。
5. **导出**：按需点 SVG / JSON / CSV / 3D曲线 / DXF / OBJ / glTF / 运动模型。

> 未标定前，导出的 mm 坐标只是像素占位；**先标定再导出**。

## 二、描图器（主面板）

### 1. 实验条件
记录这份数据对应的时间、温度、湿度。可手填，也可先选一组常用条件（25°C·65% / 22°C·70% 等）再改；「填当前时间」自动写入本机时间。这些信息会存进工程文件，预览面板载入后显示同一组条件。

### 2. 标定（像素 → mm）
| 按钮 | 操作 |
|------|------|
| ① 设原点 | 点一下画面格子交点，作为坐标 (0, 0) |
| ② 量一格 | 点两个已知间距的格子点，间距等于下方格边毫米数 |
| 1cm | 一键把格边填成 10 mm |

标定完成后侧栏显示原点像素坐标与 px/mm 比例尺。

### 3. 这一次的活动范围（八字包络框）
蚕的头部运动近似「八字」，单次包络约 1.5×1 格，个体之间大小不同，因此用手画框记录本次活动范围：

- **拖一个新框**：按住拖出新框，编号自动加一；新框不会清掉已有框和丝线。
- **挪动 / 缩放框**：点中框后拖动；拖四角或四边改大小。
- **再放 1.5×1.5 框**：按当前标定放一个参考框。
- **删除选中框**：只删框，不删丝线。

框选范围会写进运动模型的 `behaviorUnits`。

### 4. 蚕编号与描线
- **数字键 1–9** 切换当前蚕；「＋ 新蚕编号」增加下一号。
- **按住拖动** = 沿丝路连续描一笔；**轻点** = 记一个单点。
- 操作按钮：撤销上一笔（Ctrl+Z）、撤销上一点（Ctrl+Shift+Z）、重做（Ctrl+Y）、清空本蚕（无快捷键，防误触）。

### 5. 视频片段
长视频按固定时长切成多段（默认每段 15 s），逐段描线。「上一段 / 下一段」（快捷键 `[` / `]`）跳转；文件仍在本地，不重新编码。

### 6. 描线防抖 / 平滑
抬笔后统一处理，与描线快慢无关：

- **均匀点距**：按弧长均匀重采样，避免快描点疏、慢描点密。
- **平滑强度**：Chaikin 曲线平滑程度。
- **微抖过滤**：滤掉数位板/手的细小抖动。

4K 素材会自动建议一个均匀点距（约 `视频宽度/270` px）。

### 7. 曲线样式（当前蚕）
| 项 | 说明 |
|----|------|
| 颜色 | 当前蚕轨迹颜色 |
| 头端粗 / 中段粗 / 尾端粗 | 沿曲线方向的线宽渐变；每笔单独渐变，不是整条一根参数 |
| 透明度 | 轨迹不透明度 |
| 材质 | line（线）/ ribbon（丝带）/ tube（管状高光）/ silk（蚕丝光泽） |

「应用到所有蚕」把当前样式复制给其余蚕。

### 8. 笔间连接 & 统一轨迹
- **笔间平滑连接**（快捷键 `B`）：多笔丝合成一条从 u=0→1 的完整过程，连接处用三次 Bézier 曲线过渡，不是生硬直线；**过渡张力**控制弯曲程度。分段数据仍单独保留。
- **连接规则应用到所有蚕**：把连接开关与张力复制给其余蚕。
- **导出运动模型 JSON**：含步长/转角/线宽统计、合成配方草图、八字范围（`behaviorUnits`）。

### 9. 显示
- 开关：坐标网格、轨迹、采样点。
- **导出当前画面 PNG**：把当前画布截图存图。

### 10. 三维导出选项
- **坐标系**：Rhino（X,Y 地平面，Z 上）/ Blender（同左，导入后可用）。
- 可选：导出统一曲线 u∈[0,1] + 分段表；JSON 含每点半径（width_mm）；JSON 保留像素坐标备查；SVG 导出可变宽度丝带。
- 每笔丝单独成一条曲线，便于在 Rhino / Blender 里重建曲线、放样、挤管。

### 11. 统计 / 点序播放
- **统计**：当前各蚕点数等信息。
- **点序播放**：按弧长点序预览当前蚕轨迹（与视频时间无关），可调点/秒，「复位」回到起点。

### 12. 自动追踪导入
`tracking/` 目录下 Python 脚本产出的 JSON（`t, x, y` 为像素坐标）可直接导入，**默认作为新蚕加入，不覆盖现有数据**；导入后仍需手动核对修正。

## 三、吐丝运动预览（右侧面板）

### 1. 播放
- **点/秒**：回放速度；**统一 u**：按弧长参数播放；**循环本轨迹**。
- 多条描好的蚕在「轨迹」标签里切换，当前蚕高亮。
- 显示开关：丝线、正在爬的蚕、留下经过的蚕体、采样点、活动范围框。
- **材质**：蚕丝光泽 / 丝带 / 细线；**俯仰**（0=俯视）与旋转角度；**导出当前画面 PNG**。

### 2. 向旁边扩散
只能点亮上下左右相邻的格子。下一格不是另画一条线接过去，而是把第一格的笔迹再走一遍，慢慢漂进旁边那一格（整段略转、略缩放，不会点点乱抖）；再点一次取消。「清空点亮格」复位。

### 3. 合成扰动
- **噪声**：受控随机幅度；**种子**：固定种子可复现同一轮合成。
- **合成新轮**：在实测/上一轮基础上加受控随机，形态可辨，**非真实测量**。

### 4. Digital Habitat（数字蚕室，整屏区块）
> 温湿度到速度、摆动、停顿的换算是演示模型（habitat-demo-0.1），**不是本项目测得的生理规律**；原始描图轨迹只读，不会被模拟覆盖。

**打开方式**：从顶栏「进入 Digital Habitat」或页面中间那条「↓ 向下进入 Digital Habitat」滚下去。蚕室不是预览面板的一部分，它独占一整屏宽。

**侧栏收展**：蚕室顶部的「收起环境 / 展开环境」「收起个体 / 展开个体」随时切换左右侧栏；按钮按下时变绿并改文案，底部会弹一条提示确认「已收起 / 已展开」。窄屏（≤860px）下侧栏改为覆盖式抽屉，同样用这两个按钮开关。

- **气候·演示**（左侧栏）：温度、湿度滑杆，实时显示演示速度、摆动、停顿倾向。
- **场地**（左侧栏）：正方 / 长方 / 圆形。
- **桑叶障碍**（左侧栏）：背景叶只是远景；放入场地的叶子会挡住蚕。可左转、右转、删除。
- **个体**（右侧栏）：
  - 描图/预览里有数据的蚕会**自动同步**进来，卡片标「实测」；蚕室顶部会显示「实测 N 只 · 演示 N 只」，滚到蚕室时还会自动再同步一次。
  - **拖拽放置**：按住任意蚕卡片拖到场地，鼠标旁会出现跟随的标签（绿色=可放入，红色=被桑叶或边界挡住），场地边框同时变成绿色/红色虚线；松手后底部弹出「已放入」或「放不进去，换个位置」。
  - **随机演示蚕**：默认不生成；需要演示随机游走时，点「添加随机演示蚕」，卡片标「演示」。
  - **选中调整**：点选个体后，右侧滑杆改位置 X / 位置 Y / 旋转 / 缩放（实测个体可用旋转缩放）；勾选「沿实测轨迹爬行」让蚕头沿路径前进；「居中复位」回中心，「移除该个体」删除。演示蚕不支持旋转/缩放/跟爬，这几条滑杆会变灰不可拖，避免误操作。
  - 在场地里直接拖动已放置的蚕也可以移动，松手后提示已移动，再用右侧滑杆微调。
- **记录**：保存场景 JSON（保留实测个体的轨迹与位置/旋转/缩放，以及演示蚕状态）；「铺入只读预览轨迹」只是变淡的底图，不可操作；「去掉底图」清除。

### 5. 工程
预览面板可独立保存/载入工程，也可载入 JSON；「合成新轮」在实测轨迹上派生新的一轮。

## 四、导出格式对照

| 按钮 | 文件 | 用途 / 导入方式 |
|------|------|----------------|
| SVG | 矢量路径 | Illustrator / Rhino 直接打开 |
| JSON | 工程数据 | 含分段曲线、样式、标定；可重新打开继续描 |
| CSV | 表格点位 | `t, id, x_px, y_px, x_mm, y_mm`，供表格/Grasshopper 复核 |
| 3D曲线 | `curves-3d.json` | 三维曲线包，含统一轨迹 u=0→1 与分段表 |
| DXF | CAD 交换 | Rhino `_Import` 导入 |
| OBJ | 网格/曲线 | Blender 导入 |
| glTF | 管线格式 | Blender / 实时管线导入 |
| Rhino .py | Python 脚本 | 在 Rhino 内运行，生成可编辑曲线对象 |
| Blender .py | Python 脚本 | 在 Blender 内运行，生成可编辑曲线对象 |
| 运动模型 | `motion-model.json` | 轨迹统计 + 合成配方 + 八字范围，供批量生成与 TD/p5 二次创作 |

## 六、注意事项

- **先标定再导出**：未标定时 mm 坐标为像素占位。
- **视频本地处理**：不上传；`file://` 直接打开 HTML 若样片载入失败，用「载入视频」手动选本地 MP4。
- **自动追踪结果仅作初稿**：`tracking/` 脚本的 JSON 导入后需要人工核对头尾与断连。
- **4K 性能**：大数据量描线/导出若卡顿，可先按 15 s 分段处理。
- **演示模型不等于实测**：Digital Habitat 里的温湿度→行为换算为演示公式，合成轨迹带受控随机，不能作为真实生理结论引用。
