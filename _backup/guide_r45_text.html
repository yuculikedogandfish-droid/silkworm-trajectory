01三分钟上手

整个流程就四步：放块 → 改形状 → 放蚕 → 导出。

  1. 放一块“织网单元”
    点右栏「添加织网单元」。场地上出现一个方块，里面已经在织丝了。
  2. 点它一下，就地改形状
    点格子＝进入这一格的编辑（右上角按钮会变成「退出编辑」）。想改别的格，直接点别的格；点场地空白处就退出。
  3. 把蚕指定进来
    先在左边描图器里描好轨迹，点「重新同步实测轨迹」，蚕就进场了。再在右栏选“这一格用哪只蚕”。
  4. 导出
    左栏底部选分辨率 →「导出视频」或「导出当前画面 PNG」。要拿去给母版软件用的，点「导出母版场景 JSON」。
先别记细节：操作顺序永远是“先选材料、再改形状、最后导出”。任何时候按 Ctrl+Z 可以退回上一步。

02界面地图

屏幕分成四块，各管一件事。

位置管什么
左栏温度/湿度（只影响演示动画的手感）、场地形状、丝线与蚕的观感、实测轨迹入室、存盘、导出。
中间场地本身。所有格子、蚕、丝都在这里长出来。滚轮缩放、按住空白拖动画布。
右栏「个体与图层」（每块格子、每只蚕都是一层，可单独显隐、锁定、编组、整组拖动）；选中之后的「选中调整」滑条。
底部时间轴：「开始 / 暂停 / 继续」＋一条可以拖的进度条，拖到哪儿就停在哪儿。
右边两栏（左栏、右栏）内容多，鼠标移到栏上滚轮就能上下翻；中间场地永远完整显示，不用滚。

03点一下就进编辑（不用先点按钮）

在场地里点哪个格子，就在改哪个格子。这就是编辑状态的全部开关。

想删掉一整块：格内右键最下面的「删除这一块织网单元」，或者选中这块之后按右栏「删除这一块」——两个入口做的是同一件事，删错都能 Ctrl+Z 撤回。

你做的事会发生什么
点一个格子进入这一格的编辑，右上面板出现这条格子的尺寸/旋转等滑条，格子四角四边出现白色手柄。
编辑中再点另一个格子直接切过去改那一格（不用先“退出编辑”）。
点场地空白处退出编辑，手柄和虚线提示都消失。
点右栏「退出编辑」同上，退出编辑。

格内右键：想加什么，菜单里直接有

在格子里的“空白处”按右键，菜单就是一份添加清单，点哪条就从那儿开始画（下图）：

菜单项干什么
添加孔洞（放在这一点）在点的位置开一个圆孔，丝会绕开它。
添加缺口（放在这一点）立刻在你点的位置生成一个缺口（先给一个六边形，看得见、能马上改），拖白点就能变成你要的形状。
重画缺口（点几下围一圈）把这一格旧的缺口清掉，自己点几下围一圈，双击收尾，首尾接成光滑曲线。
添加壁（从这里起笔）画一道看不见的墙：丝不穿过去，蚕会绕路；壁只在编辑时才显虚线。
添加丝路（从这里起笔）画一条“大路”，蚕会沿着它多绕几圈，所以那一段会更密。
重设整块外框（点几下围一圈）把这一块格子的外形整个换掉（可以做成一圈不规则的外形）。
清掉这一格的形状（孔/缺口/壁/丝路）这一格的所有自定义形状清空，回到默认。
删除这一块织网单元（整块消失）把这一整块从场地里删掉（不是只删形状）。删错按 Ctrl+Z 撤回。

右键压在手柄上：出的是删除菜单

鼠标正好压在白点（锚点）或孔上按右键，菜单会变成 「删除这个锚点 / 删除整个缺口 / 删除这个孔」。压锚点只删一个点，压孔心才删整个孔——不会误删。

04改形状的手感（照平面软件的老规矩来）

一句话：点线加锚点，拖点挪位置，右键删东西。不需要先选工具再点按钮。

你的动作结果
拖白色方点挪这个锚点，缺口跟着它变形（始终光滑，不会变折线）。
孔洞圈上的青点拖它就改孔径，大小不设上限——可以一直拉到几乎占满整格。
点在这条缺口的线上就在你点的位置插一个锚点，手不松就能直接拖着走（跟钢笔工具一样）。点歪了不会乱加点。
拖边中间的小空心方点同样是在这一段上加一个锚点。
右键压在白点菜单：删这个锚点 / 删整个缺口。
双击画线时＝收尾；编辑时＝结束这一轮的造型。
点「重画缺口」清掉这一格的缺口，重新点几下围一圈。

画的时候就是曲线，不是先折线后变曲线

点第一下、第二下……屏幕上那条虚线已经按光滑曲线显示；收尾时形状和你在画的时候看到的一致。

曲线本身也做了加固：锚点疏密不均、甚至两个点挤在一起，也不会鼓出自交的小圈或尖角。点线上加锚点时，如果离已有锚点太近（小于约 10px）会不再插入，避免锚点叠在一起把形状搞乱。

画出来是个三角形？

点 3 下再收尾，形状本来就是个三角。要圆一点、要不规则，就多点几下（5–6 个点最自然）；或者直接用「添加缺口」先拿到一个六边形，再逐个拖锚点。想彻底重来就点「重画缺口」。

四个形状分别是什么感觉

形状作用与观感
孔洞圆形空洞，边缘干净，丝全部绕开。大小可以拉。
缺口任意形状的空洞：不圆、可大可小、按你点的点连成光滑闭合曲线。丝绕开，蚕不会钻进去。
壁看不见的墙（只在编辑时显示虚线）。蚕碰到会沿墙绕行，不会穿过去。
丝路蚕要走的“主干道”。走过的地方丝会叠得更密，形成一条明显的路径。
格子最大可以拉到 1200×1200，孔洞和缺口都不限大小，想做一块很大的织片就先把格子拉大再造型。

05把蚕放进来

蚕来自左边的描图器：描好 → 同步 → 指定给哪一格。

  1. 在描图器里描轨迹
    左上角「载入视频」，标定，然后顺着蚕按住拖动画线（或轻点记点），一条一条描。可以给每条起编号。
  2. 回蚕室同步
    左栏「实测轨迹入室」→「重新同步实测轨迹」，蚕和它的丝就进场了。描图器新增/改过的，再按一次即可。
  3. 指定这一格用哪只蚕
    选中格子后，右栏最下面「这一格用哪只蚕」：默认「合并丝路」，也可以只选某一只。一只蚕可以同时用在不同格子——它只是一种“蚕”，不是被搬走的一只，所以不会从别的格子里消失。
  4. 决定从哪儿起步
    把蚕拖到格子里放手，它就从你放手的位置开始；不拖的话按随机的点起步，不会排成一排。
没有真实数据也能先做效果：右栏「添加辅块群」会用演示丝路铺一片格子，用来试版面。演示蚕只是占位，最终成品请用实测数据。

06让丝好看、把不想看的藏起来

左栏「丝线与蚕的观感」四个滑条 + 一个下拉，都是实时生效的。

控制调大 / 调小会怎样
蚕大小改蚕的体型。格子里显得太大或太小，就调这个。
重复密度同一段路走几遍，越大越密。
丝线粗细丝的线宽，默认 0.7；要更明显就拉到 1.2 以上。
丝线亮度丝的明暗，配合屏体亮度调。
丝线观感真丝（默认）/ 其他几种材质气质，仅供观感。

隐藏

  • 左栏勾「隐藏所有蚕体（只留丝）」：只留下丝，不看蚕。
  • 左栏勾「隐藏所有丝迹（只留蚕）」：只看蚕怎么爬。
  • 右栏每一层右边有「显 / 隐」，点一下单独隐藏这一层；组行上的「显」一次管整组。
  • 隐藏只影响屏幕预览与导出画面，工程数据不会丢，取消勾选就回来。

07存盘与恢复（不会白干）

三重保险：自动存 → 存工程文件 → 换机器载入。

方式说明
自动保存每 3 秒存一次，关页面/切标签页前再存一次；下次打开同一个网页，500 毫秒后自动接着上次。左栏能看到“自动保存：时间 已存”。
保存工程（.json）把整场（格子、形状、蚕、参数）存成一个文件，可备份、可发给别人。
载入工程（.json）把工程文件重新装回来，换电脑也能继续。
画到一半可以随时停：改到一半也不算“未完成”，自动保存照旧。要在两个方案之间来回比，就先「保存工程」存成 A、B 两个文件。

08导出：视频 / 图片 / 母版

全部在网页里完成，不需要再回本地软件加工。

① 视频

左栏「视频导出」区：先选分辨率，再选时长、帧率、码率，然后点「录制」。

分辨率（按屏体选）适合
854×480（16:9 快）先看动态、快速试片
1280×720 / 1920×1080（16:9）横屏展示、投影
1280×960 / 1920×1440（4:3）4:3 屏体，1280×960 用于快速预览
2048×1536（4:3 交付）默认交付档，约 3.14 m × 2.36 m 屏体实拍够用
2093×1573（4:3 屏体理论）屏体物理点数，1:1 对点
2560×1920 / 3840×2880（4:3 2K/4K）要留放大余量、做素材存档
2419×1360（旧母版 16:9）沿用旧母版工程时用
自定义…自己填宽高和比例，右侧会提示当前比例

时长 5–120 秒，帧率 24 / 30 / 60，码率 8 / 16 / 28 / 40 Mbps。要更长更清楚：时长按片子定、帧率 30 或 60、码率 28–40，分辨率不低于 2048×1536。

② 图片（PNG）

左栏「导出当前画面 PNG」，跟视频用同一套分辨率选择（含自定义）。先把时间轴拖到想要的那一帧，再点导出，得到的就是那一刻的静帧。

③ 给母版软件（后期/上屏机）

导出项用途
母版场景 JSON母版渲染的输入：曲线 + 单元几何，喂给 Rhino / Blender / TouchDesigner 都行
导出曲线 JSON / 单元几何 SVG / DXF只要曲线或只要几何时用
复制母版渲染命令把命令文本拷到剪贴板，给跑母版的人
导出前把要隐藏的蚕/丝藏好——隐藏会如实进入导出画面，但虚线框、锚点这些编辑辅助线不会出现在成品里。

09名词表（这些词在界面里出现）

词意思
织网单元场地里的一块方形“织片”，里面自己会长丝、放蚕。一整场由若干块拼成。
辅块群一次铺出很多块，用演示丝路做版面试验。
孔洞圆形的空洞。
缺口任意形状的空洞（你点几下围出来的那块）。
壁看不见的墙，只挡蚕和丝，编辑时显示虚线。
丝路蚕的主干道，沿着它多走几圈，那一段更密。

10常见问题

点格子没反应？
先确认没在别的地方画线（比如正画着缺口）。按 Esc 或点一下场地空白，再点格子。
缺口越点越复杂，想重来？
在这一格里右键 →「重画缺口（点几下围一圈）」，旧的清掉，重新点几下围一圈。
缺口画出来是个角很尖的三角形？
只有 3 个点就会是三角：多点两下，或者先用「添加缺口」生成六边形再拖锚点改形。
丝跑出格子外面了？
把格子拉大（最大 1200），或把丝线粗细/蚕大小调小；导出前可以把看不到的部分用缺口/壁裁掉。
蚕在格子里显得太大？
左栏「蚕大小」往小调，或右栏「缩放」单独调这一块。
关闭网页后再打开，东西还在吗？
在。自动保存会恢复上一场。要长期保留就「保存工程（.json）」存成文件。
导出视频很慢？
分辨率、帧率、时长一起决定时长。先用 854×480 / 30 秒试片，定稿再上 2048×1536。

11图层、分组与排版（r39 之后的新东西）

右栏只有一个列表，每块织网单元、每只蚕都是其中的一层。先在列表里点它，场地上就会画出虚线框告诉你“选中的是这一块”。

行上的东西点它会怎样
勾选框多选。勾两层以上就能编组、对齐、阵列。
缩略图这一块当前的样子，随织丝实时更新，不用回场地上找。
层名（单元 1 / 蚕 1）选中这一层，场地上出现青绿虚线框；右栏下面「选中调整」也切到它。
显 / 隐只影响画面和导出，数据不丢，再点一下就回来。
⋯弹出小菜单：锁定这一层、上移一层、下移一层、移出所在组、删掉这一块。

组：把几层捆在一起

勾上要捆的层 → 点「编组所选」→ 起个名字。组行上：▾ 收起/展开，组名 一点＝整组选中，后面的数字是层数，显 管整组显隐，改 改名，✕ 解散（只散组，不删块）。「并入同组」把勾选的层塞进已有的组里。

整组一起挪：拖组里任意一块，整组跟着走；没编组的单块只动它自己。指针落在那块的手柄（角、边中点、中心）附近时仍交给手柄，不会抢。

框选：在空地拉一个框

按住空地拖动，超过一点点距离才算框选（所以普通点击不会误选）。框到的块全部选中；按住 Shift 拉框是追加。在选区里点右键：可以一次删除选中的所有块、把它们编成一组、或取消选择；点选区外的空白就取消选择。

吸附：拖到位会“啪”地对齐

拖动时自动贴别人的边、中线，或者与旁边两块保持同一道缝；命中时画粉色虚线做参考。按住 Ctrl（Mac 上 ⌘）拖，就临时不吸附，想微调时用。

对齐、等距、阵列

按钮作用
左 / 横中 / 右 / 上 / 竖中 / 下把选中的几块按某个方向对齐（边缘或中线）。
水平等距 / 垂直等距首尾不动，中间几块按等间距重新摆。
列 / 排 / 缝 → 复制只选一块时用：按列数×排数复制，缝是块与块之间的空隙。复制出来的是同样的尺寸、孔洞与缺口。
方向键 / Shift + 方向键选中后微调 1 像素 / 10 像素。

层序与锁定

⋯ 里的「上移一层 / 下移一层」会真的改变叠放次序（有交叠时谁盖谁）；「锁定这一层」之后它不再跟着拖动，也不会被方向键挪走，适合已经把位置定死的块。

组关系会写进工程 JSON：换机器载入工程，组、组名、层序都还在。本机浏览器里也留了一份缓存，方便下次直接接着用。

12从参考图识别版式（r43 之后）

把一张参考图拖进去，它会自己找格子、找孔洞，先给你看预览，确认无误再生成到场地。识别本身不会动场地。

四步

  1. 拖图：点中间上方的「从图片识别版式」展开，把图片拖进框里（或点框选文件），一次一张。
  2. 识别并预览：等一两秒，场地上叠出原图和识别框。
  3. 校对：点「点预览框补块 / 去块」，再点某个框就能切换“这块要 / 不要”；再点一次按钮退出校对。
  4. 生成到场地（新增）：按每块真实的宽、高、位置生成。「替换现有块群」会先删掉场上已有的块，慎用。
控件什么时候调
列数 / 排数都填 0＝按真实轮廓自动找，每块大小可以不一样、允许错位和窄条；填了数字＝按固定网格均分（老方式）。
丝多稀也算一块丝很稀的块被漏掉时往左调；黑底被误当成块时往右调。
多小的洞才保留小洞太多就往右调，小洞被吃掉就往左调。
识别孔洞 / 识别缺口只要其中一类时，把另一类勾掉。
预览时叠上原图对比关掉就只看识别框，方便检查有没有多出来的块。
生成之后每一块都是普通织网单元：可以拖锚点改缺口、可以编组、可以整组拖动，也可以用框选＋对齐继续排版。
